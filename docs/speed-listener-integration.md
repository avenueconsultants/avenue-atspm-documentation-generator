## Verified source contract

- The file `SpeedListenerConfiguration.cs` declares **EventListenerConfiguration**
  through its `[ConfigurationSection]` attribute. The generated environment names
  therefore use `EventListenerConfiguration__`, not the file name.
- `HostBootstrapper` binds **SpeedEmitterConfiguration** by that exact name and
  validates a nonblank host, port 1–65535 and positive transmission interval.
  The emitter command can override its bound values.
- The emitter defaults are host `127.0.0.1`, port `1088`, `ProtocolType.Udp` and
  interval `100` milliseconds. The declared listener source defaults are
  `BatchSize = 50_000`, `UdpPort = 10088` and lowercase `threads = 50`.
  The snapshot retains source expressions; the example JSON now correctly uses
  numeric `50000` for the batch size.
- Seven unique structured emitter events, IDs 2001–2007, are in the log page.
  The listener declares no `[LoggerMessage]` events in this repository.
- The listener command has no handler, the listener background service throws
  `NotImplementedException`, and no local code binds EventListenerConfiguration.
  Its page is explicitly labeled as a **declared** configuration reference.
  It does not establish that a listener currently runs or reads those settings.

The generated ProtocolType table lists all members of the .NET enum. The local CLI
describes UDP/TCP and the emitter's send method uses UDP or its other branch.
The enum member list is not a tested promise that every value has distinct or
supported runtime behavior. The consumer README explains this distinction.
