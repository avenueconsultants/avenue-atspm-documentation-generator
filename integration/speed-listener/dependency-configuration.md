# Dependency-provided configuration

`SpeedListener/SpeedListener/SpeedListener.csproj` references
`Utah.Udot.Atspm.Infrastructure` version **5.3.1**. `HostBootstrapper` calls
`AddAtspmDbContext(hostContext)` and `AddAtspmEFConfigRepositories()` from that
package when the emitter host starts.

The generated [emitter](autogenerated/speed-emitter.md) and
[declared listener](autogenerated/event-listener.md) pages are based on the C#
source committed in this repository. They do not enumerate configuration classes
that exist only inside the versioned package. The package registration methods
are evidence of a dependency, not a complete list of keys or runtime defaults.

When reviewing deployment changes, inspect the exact package version and its
source or package documentation for database context and repository settings.
Compare any package upgrade with its configuration contract. Do not infer missing
settings from an empty local scan or copy secret connection values into this map.
The shared generator's later external-type support can add those settings with
explicit version and source provenance once that implementation is reviewed.
